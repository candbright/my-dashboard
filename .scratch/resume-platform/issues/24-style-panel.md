# 24 — 自定义样式面板

- **Type**：task
- **Status**：ready-for-agent
- **Blocked by**：19（展示态）、20（模板架构）
- **Blocks**：—
- **ADR**：[ADR-0004](../../../docs/adr/0004-presentation-state-in-jsonb.md)、[ADR-0008](../../../docs/adr/0008-visual-templates-first-is-ats-safe.md)

## 背景

Reactive Resume 有 **Custom Styles**：主色、字体、字号缩放、间距，且其用户自定义 CSS 是**模板感知**的（每套模板自带 `semantic.ts` 描述 CSS 钩子）。

本项目**完全没有样式定制能力**——所有渲染细节硬编码。

展示态列（工单 19）已就位，本工单是它的 UI。

## 任务

1. 新增样式面板组件，编辑展示态的以下维度：
   - **主色**（受 ADR-0004 约束：**冷色与纯黑被服务端拒绝**，前端应只提供合规色板）
   - **字体族**：衬线（Noto Serif SC）/ 无衬线
   - **字号缩放**：如 0.9 / 1.0 / 1.1
   - **行距**
   - **页边距**
   - **章节顺序**（拖拽排序，复用 `ResumeEditor` 已有的 framer-motion `Reorder`）
2. **实时预览**——改动即时反映到预览区
3. **保存走乐观锁**（工单 12），与内容共用 `version`
4. **不触发内容版本历史**（工单 16 / ADR-0004）
5. **色板必须是设计规范内的颜色**：大地色系（stone / amber / olive / sage）——这既是产品约束也是 ATS 考量（高对比度）
6. 遵守 `AGENTS.md`：UI 组件库、`rounded-full` 控件、`duration-500`

## 验收标准

- [ ] 上述六个维度均可调整并生效
- [ ] 实时预览
- [ ] 色板只含合规颜色；尝试非法颜色时前端阻止、后端拒绝
- [ ] 保存不产生内容版本历史
- [ ] 与内容编辑并发时正确返回 409
- [ ] 样式变更不影响 ATS 体检的通过状态（单栏结构不变）
- [ ] 视觉符合 Natural Organic 规范
- [ ] 移动端可用

## 备注

- ⚠️ **`fontScale` 与 `pageMargin` 是"一页纸自动收缩"（工单 28）的调节旋钮**——本工单先把它们做成可手动调，工单 28 再加自动逻辑。
- 国内竞品的对应能力是职徒的"一键统一切换行距/页边距/颜色"——本工单落成后，工单 28 可以在此之上加"一键"预设。
