# 04 — 分页语义化

- **Type**：task
- **Status**：ready-for-agent
- **Blocked by**：03（打印导出）
- **Blocks**：—
- **ADR**：[ADR-0001](../../../docs/adr/0001-render-engine-selection.md)

## 背景

当前分页是 `while (heightLeft > 0)` 里的**原始像素高度切片**——在任意位置切开，会把一条工作经历从中间劈开，也会让章节标题孤零零留在上一页末尾。

`ResumePrintView.tsx` 是 A4 打印视图（约 326 行），已有正确的结构可以利用。

## 任务

1. **条目级不断裂**：给每个经历/教育/项目条目加 `break-inside: avoid`
2. **章节标题不与首条分离**：标题与其后第一个条目视为一个整体（用 wrapper 元素包住，或 `break-after: avoid`）
3. **续页重复表头**：多页时，每页顶部重复姓名与联系方式（用 `@page` 边距框，或在打印视图中为每页构造表头）
4. **消除孤寡行**：`orphans: 2; widows: 2;`
5. 确保 1 页与多页两种情况的输出都正确

## 验收标准

- [ ] 不存在被劈开的条目（目视检查 2–3 页的真实简历）
- [ ] 章节标题不会单独出现在页尾
- [ ] 多页时每页顶部都有姓名与联系方式
- [ ] 单页简历不受影响
- [ ] 1 页与 3 页两种样本都有测试或快照记录

## 备注

- 这些正是 Forme / Typst 原生支持而浏览器打印需要手写的部分（ADR-0001 的权衡表）。
- 若 CSS 边距框在目标浏览器支持不佳，退化为"为每页显式构造表头元素"的方案——**但必须在代码里注明是退化方案**。

### ⚠️ 采用了"为每页显式构造表头"的方案，而非 CSS 边距框

备注里要求的退化方案，**就是实际采用的方案**，原因：

**目标浏览器（Chromium）不支持 `@page` 边距框**（`@top-center` 等）。页眉要在每页重复，就必须是每页里真实存在的标记——而这意味着内容必须被**主动**切分，不能交给浏览器。

所以分工是：

- **CSS 负责它擅长的部分**：条目 `break-inside: avoid`、`orphans`/`widows`、页与页之间的 `break-before: page`。
- **`paginateBlocks` 决定哪些块共处一页**，并让每页携带表头。

因此这不是"退化的兜底"，而是 ADR-0001 权衡表里"浏览器打印需要手写"的那部分的正解。⚠️ **阶段四换成渲染服务时，这一整块可以删掉**——Forme/Typst 原生支持分页与重复表头。

### 过程中发现并修掉的三个真实缺陷

**1. 分页单位选错：按"节"切分而非按"条目"，导致长节独霸一页。**
最初把每个 `<section>` 当作一个不可分块。实测 3 条工作经历的整节高 **1211px**，超过页高 986px，于是触发"超大块"规则——结果**第 1 页只剩表头**（42 字符），整节被推到第 2 页。

这才是本工单的核心：`break-inside: avoid` 在块本身高于一页时**无解**，所以不可分的单位必须是**条目**，而节**本来就应该能跨页**。`flattenPrintFlow` 因此把节展平成"标题 + 各条目"。

**2. 第 1 页丢掉了姓名与联系方式。**
早先版本把表头只放在 `index > 0` 的页上，理由是"第 1 页本来就以它开头"——**但表头块被移出内容流了**，所以第 1 页实际上既无姓名也无联系方式。改为**每一页都带表头**（读者看到第 3 页时不必回翻确认这是谁的简历）。

**3. 去重按 HTML 字符串做，把内容相同的条目当成了重复项。**
`makePage` 用 `Set<string>` 记录已输出的块。两个内容完全相同的条目——**同一职位在两家公司、或两条空描述**——会被误判为重复而**静默丢掉一条**。改为按对象身份去重。

前两个是浏览器验证抓出来的；第三个是单元测试抓出来的（`fills a page before breaking rather than breaking early` 报"期望 3 得到 1"）。

### 一处需要留意的设计取舍

分页在**离屏容器**里测量（`position: fixed; left: -9999px`）。这个容器宽度与页面内容盒一致，因此换行与真实打印一致。但若将来打印视图引入**依赖视口高度**的布局（如 `100vh`），测量会失真——届时需要改成用真实 A4 尺寸的 iframe 承载打印视图再测量。

### 遗留（交后续工单）

- 分页目前**不重复小节标题**（只重复页眉）。若某节跨页，第 2 页不会出现"工作经历（续）"。这是有意为之——续页标题需要额外设计，且不属于本工单验收范围。
- 超长单条目（高于整页）仍会被标记 `hasOversizedBlock` 并独占一页，不做内部拆分。这是诚实的行为，不是遗留缺陷：`break-inside: avoid` 在该情况下无法满足，标注出来好过假装保住了整条。
